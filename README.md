# Small Object Detection (AI-TOD-v2 Benchmark Suite)

Benchmarking and ablation study suite for tiny and small object detection on aerial imagery (AI-TOD-v2), contrasting YOLOv8s and YOLO26s baselines with architectural ablations (P2 feature stride, SAHI tiling inference, NWD loss).

## Setup

```powershell
# Sync project dependencies
uv sync
```

## CLI Usage

```powershell
# Show top-level commands
uv run python -m src.cli --help
```
